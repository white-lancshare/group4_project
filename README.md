EMPLOYEE MANAGEMENT SYETEM

About The Project

This project is an Employee Management System built with Node.js and Express.js. It was created as a team project to help us practise backend development and understand how the MVC architecture works.

The system focuses on employee details, departments, and job roles. It allows users to create, view, update, and delete employee records.

We also used Git and GitHub to manage our code, track changes, and collaborate as a team.

Technologies Used

* Node.js
* Express.js
* JavaScript
* Git
* GitHub
* Postman

Project Features

* Add new employees.
* View all employees.
* View an employee by ID.
* Update employee details.
* Delete an employee.


Project Structure

The project is organised into different folders to make the code easier to manage.

* Model: Handles the data.
* Controller: Contains the logic for handling requests.
* Router: Defines the routes for the API.
* Server: Runs the application.
* Middleware: Handles the logger

How to Run the Project

1. Clone the Repository

git clone YOUR_REPOSITORY_URL

2. Open the Project Folder

cd group4_project

3. Install Dependencies

npm install

4. Start the Server

node server.js

If the server starts successfully, you can test the API using Postman.

API Endpoints

Method	Endpoint	Description
get /allEmployees  Get all employees
get  /getEmployees/:id Get one employee by id
post  /newEmployee     To create a new employee
put  /updateEmployee/:id'  To update an employee's details
delete  /deleteEmployee/:id  To delete an employee
